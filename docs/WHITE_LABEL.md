# White-label для реселлеров

Панель поддерживает базовый white-label через модель `Theme`
(`apps/panel_settings/models.py`):

- `product_name` — название, отображаемое в топбаре и `<title>`
- `logo_url` — логотип вместо текстового названия
- `favicon_url` — фавикон вкладки браузера
- 9 цветовых переменных — полная перекраска интерфейса под бренд

## Ограничение текущей реализации

Тема сейчас **глобальная** (одна активная тема на всю инсталляцию —
`Theme.is_active`). Это подходит модели "продал self-hosted лицензию —
клиент сам красит свою инсталляцию под себя" (см. `docs/LICENSING.md`).

Если нужен **per-reseller white-label на одной инсталляции** (несколько
реселлеров с разным брендом на одном сервере/домене), потребуется:

1. Добавить `Theme.reseller = models.ForeignKey(User, null=True, blank=True)`
2. В `apps/panel_settings/context_processors.py::active_theme` выбирать
   тему по `request.user.parent_reseller` (или по поддомену, если
   планируется `reseller1.yourpanel.com`, `reseller2.yourpanel.com`)
3. Для полной изоляции брендинга в письмах/Telegram-боте — прокидывать
   `product_name`/`logo_url` в контекст уведомлений аналогично.

Это осознанно не реализовано "про запас" — добавляй, когда появится
конкретный реселлер, которому это нужно, чтобы не усложнять модель
данных заранее.
